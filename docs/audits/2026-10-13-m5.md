## Findings

### High

- **H1 Save As inspected directories on the UI thread.** The Save As dialog
  result called `files::project_file_for`, which checks `Samples/` and scans
  for neighboring project files before the background save starts. A slow or
  network folder could stall the interface, breaking the disk-work rule.
  Project-folder detection now runs in `files::save_now` on the worker, with
  a regression test in `files.rs`; the test and full gates remain pending.

### Medium

- **M1 Production modules exceed the architecture guide's roughly 800-line
  threshold.** The full scan found 12: `lumen-app/src/note_editor/lane/gesture.rs`
  (1,186), `lumen-project/src/edit/record.rs` (1,071),
  `lumen-app/src/document/lanes.rs` (977), `lumen-app/src/note_editor/ui.rs`
  (924), `lumen-app/src/widgets/mod.rs` (907),
  `lumen-project/src/edit/events.rs` (881), `lumen-app/src/lanes.rs` (868),
  `lumen-app/src/lib.rs` (865), `lumen-app/src/document/notes.rs` (806),
  `lumen-app/src/theme.rs` (818), `lumen-app/src/midi_out.rs` (803), and
  `lumen-app/src/document/mod.rs` (804). Rule: split modules that mix
  concerns, and split past about 800 lines before adding more. The growing
  MIDI, editing and project code will otherwise be harder to review and
  maintain. Recorded in `KNOWN_ISSUES.md`; review boundaries and split before
  the next milestone extends them.

### Low

- **L1 Project format in the architecture table was stale.** It said v7,
  while the current model is v15. Fixed in `ARCHITECTURE.md`.
- **L2 README's current status was stale.** It said MIDI and recording were
  still to come and marked M5 proposed. Updated for the built MIDI scope and
  slice 8 closeout underway.
