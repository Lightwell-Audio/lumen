Open **Preferences…** from the app menu, or type "Preferences" in the
command palette. Type in its search box to find a setting by any of the
words listed with it.

This page is an index: it names every setting and where it lives. What a
setting does is told in the guide it links to; settings without a link get
their guide as the docs grow.
