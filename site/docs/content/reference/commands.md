Every command can be run from the command palette: press
{{ keys(id="view.palette") }} and type part of its name. The
shortcuts below are the defaults. Change any of them in **Keyboard
shortcuts** (in the app menu), and the switch at the top of this page shows
them for Windows or macOS.
